# Little Market

A pet-care and food runner English learning game.

## Play offline
Download index.html and open it in your browser. Artwork is embedded.

## Publish and update
GitHub Pages publishes from the main branch and repository root. Replace index.html in this same repository to update the existing website without changing its address.

## Keep saved progress
Progress is stored locally in each browser, not in GitHub. Updates should preserve the existing storage keys (little_market_pet_v1 and little_market_slots_v1) and save compatibility.

Before switching sites, browsers or devices, open each saved adventure and use Help > Download save backup. Import each backup on the new site. Clearing browser data can remove saves.
